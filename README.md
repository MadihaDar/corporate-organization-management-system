# Corporate Organization Management System

A console-based Corporate Organization Management System developed in **C++** that simulates the operations of a large organization by integrating multiple departments into a single application. The project applies object-oriented programming principles and advanced data structures to manage employees, finances, production, warehouses, franchises, and administrative operations.

---

## Features

- Secure user authentication
- Admin dashboard
- Employee management
- Human Resources (HR) management
- Finance management
- Warehouse management
- Production management
- Franchise management
- Data persistence using JSON
- Menu-driven console interface
